# Generador de Contraseñas Seguras

Proyecto para la materia de Seguridad Informática.

Genera contraseñas seguras usando mayúsculas, minúsculas, números y símbolos. También permite elegir la longitud, copiar la contraseña y ver su nivel de fortaleza.

## Tecnologías

- HTML
- CSS
- JavaScript

## Uso

Abre `index.html` en el navegador o publica el proyecto con GitHub Pages.
